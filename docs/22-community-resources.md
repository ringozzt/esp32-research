# 22 · 社区与官方资源导航

## 概述

信息优先级建议：**乐鑫官方文档与 GitHub** → **CSA / 标准组织** → **成熟开源项目文档** → **论坛与博客**（二手，需交叉验证）。

## 关键点

| 类型 | 资源 | 链接 |
| --- | --- | --- |
| 文档中心 | ESP-IDF / 芯片文档 | https://docs.espressif.com/ |
| 产品 | SoC / 模组 | https://www.espressif.com/en/products |
| 开发者博客 | Developer Portal | https://developer.espressif.com/ |
| 代码 | GitHub espressif | https://github.com/espressif |
| 组件 | Component Registry | https://components.espressif.com/ |
| 论坛 | ESP32 论坛 | https://esp32.com/ |
| 中文 | 乐鑫中文文档入口 / 论坛分区 | 在 docs.espressif.com 切换「中文」；论坛中文区 |
| 聊天 | 各项目 Discord/Gitter | 以项目 README 为准 |
| 视频 | 乐鑫官方与社区频道 | 检索验证，勿信搬运剪辑中的过期 API |

## 代表项目 / 资源

- ESPHome Discord / 文档：https://esphome.io/
- Tasmota Discord / 文档：https://tasmota.github.io/docs/
- Home Assistant Community：https://community.home-assistant.io/

## 最佳实践或坑

- 博客年份与 IDF 大版本不匹配时，以官方 migration guide 为准。
- 微信文章常缺版本号：当线索，不当依据。
- Issue 区搜索先于新开 bug。

## 参考链接

- [Arduino-ESP32 文档](https://docs.espressif.com/projects/arduino-esp32/en/latest/)
- 检索 QQ/电报群等非官方社群时注意诈骗与盗版工具链接。
