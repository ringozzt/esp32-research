## 今日要点

- **PlatformIO `platform-espressif32` v8.0.0**（2026-10-19）：新增 72 块开发板；Arduino core 对齐 **3.3.12**（底层 IDF **v5.5.5**）；ESP-IDF 框架路径升至 **v6.1**；Arduino 工具链 `v14.2.0+20260121`；预编译 esptool **v5.4**。Release 明确提醒 3.x 尚未包含 Arduino-ESP32 4.0 的完整 Bluetooth 重构。
- **ESP-IDF VS Code Extension v2.3.0**（GitHub 2026-09-23；官方博客 2026-10-16）：任务失败可「Ask AI to fix」、单分区 Build/Flash/Monitor、内置 Espressif Documentation / Component Registry **MCP** 服务、调试时自动加载 gdbinit / ROM 符号。
- **Arduino `ESP_Video`**（Developer Portal 2026-09-20）：在 Arduino 侧包装 IDF `esp_video`，V4L2 风格采集；**ESP32-P4** 支持 MIPI-CSI + DVP，**ESP32-S3** 支持 DVP；需 Arduino core 构建于 ESP-IDF ≥ **5.4.0**。相对经典 `esp_camera` / CameraWebServer，更适合 P4 ISP 与高分辨率路径。
- **文档索引刷新**：技术文档列表上 **ESP-IDF User Guide（SDK latest）** 各芯片目标日期为 **2026-10-25**；**ESP-Matter Programming Guide** latest 为 **2026-10-22**（非新 SDK 标签，属文档站滚动更新）。
- **社区 Matter**：`DavidvtWout/esphome-matter` 为 ESPHome 外部组件实验预览（Matter 1.5 / esp-matter；Wi-Fi 与 Thread；已测 C3/C5/C6/S3/H2；当前要求 `toolchain: platformio`）。非官方合入，YAML API 仍可能破坏性变更。
